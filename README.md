# Hospital Management System

A Java-based hospital management system using JDBC and MySQL for efficient patient and staff management.

## Features
- **Patient Management**: Add, update, and view patient records.
- **Doctor & Staff Management**: Maintain doctor and staff details.
- **Appointments**: Schedule and track patient appointments.
- **Database Integration**: Uses MySQL with JDBC for data storage and retrieval.

## Tech Stack
- **Java (Core Java, JDBC)**
- **MySQL (Database Management)**

## Setup & Installation
1. **Clone the Repository**
   ```sh
   git clone [your-repo-link]
   cd hospital-management-system
   ```
2. **Set Up Database**
   - Import the provided SQL file into MySQL.
   - Update database credentials in the Java code.
3. **Run the Application**
   - Compile and execute the Java application.
